# Декабристы — интерактивная карта

Статический сайт на Vite, JavaScript modules и Leaflet. Серверная часть не требуется: браузер загружает опубликованную Google-таблицу напрямую.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Готовый сайт находится в каталоге `dist/`. На VPS достаточно разместить его содержимое в корне сайта Nginx; Node.js на сервере не нужен.

## Данные Google Sheets

По умолчанию используется таблица проекта. Чтобы загрузить другую, вставьте ссылку или ID в поле «Своя таблица».

Таблица должна быть опубликована для просмотра всем, у кого есть ссылка. Данные считываются через Google Visualization CSV endpoint. API-ключ Google Sheets не нужен.

Распознаваемые столбцы:
- координаты — заголовок содержит `coord` или `координат`; если такого заголовка нет, используется восьмой столбец;
- изображение — заголовок содержит `picture`, `картинка` или `изображение`.

Остальные поля сохраняют исходное соответствие: название — столбец B (резервно C), описание — D, место — E, масштаб — F.

## Карты и внешние сервисы

Подложка карты сейчас использует существующий endpoint тайлов Яндекса. Перед публичным запуском проверьте актуальные условия использования Яндекс Карт и требования к атрибуции для выбранного способа получения тайлов. Атрибуция Яндекса отображается на карте.

Leaflet устанавливается как npm-зависимость и попадает в сборку сайта.

## Развёртывание

Соберите проект командой `npm run build` и скопируйте содержимое `dist/` в каталог сайта на сервере. Для Nginx используйте обычную раздачу статических файлов и настройте HTTPS. Конкретную конфигурацию можно добавить после выбора домена и каталога на VPS.
